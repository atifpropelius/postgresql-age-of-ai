# Supabase talk source map

Reviewed **16 October 2026**. Audience slides use short teaching summaries. The linked presenter references carry the exact product qualifications. Recheck plan, pricing, availability and CLI behavior before delivery.

**Source rule for future edits:** Start with [Supabase Developer Docs](https://supabase.com/docs) for product behavior, commands, security and billing. Use Supabase announcements and the named partner's own documentation for adoption or integration claims. Treat dashboard screenshots as examples of one project's UI, and verify any claim that may change before presenting it.

| 8 | New Supabase Compute versus Edge Functions and external servers | [Compute product page](https://supabase.com/compute), [October 2026 announcement](https://supabase.com/blog/select-2026-build-anything), [Edge Function limits](https://supabase.com/docs/guides/functions/limits), [database compute usage](https://supabase.com/docs/guides/platform/manage-your-usage/compute). Supabase describes Node/Deno or Dockerfile services in full Linux, public HTTP and private background jobs without a wall-clock limit. Idle services can suspend; durable local disk and in-memory continuity are not established. The current private alpha is only for internal evaluation, not production/end customers; the supplied project screenshot says no access. No price or general-availability date is claimed. |
| 9 | Optional Cloudflare gateway, custom domain and approximate rate limit | [Worker Custom Domains](https://developers.cloudflare.com/workers/configuration/routing/custom-domains/), [Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/), [Rate Limiting binding](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/), [Workers KV consistency](https://developers.cloudflare.com/kv/concepts/how-kv-works/), [Supabase Custom Domains](https://supabase.com/docs/guides/platform/custom-domains). Cloudflare is separate from Supabase. Its Worker domain is a proxy, not the Supabase add-on; $5 is a Paid-plan minimum, not a hard cap. The binding is local and approximate, and direct origin URLs may bypass the gateway. |

Plan and setup affect availability; branch data is absent by default. |
